    Review note · layout: One studio instead of three cards. Left: Layers / Assets / Genie. Center: canvas with rulers, smart guides and zoom. Right: a context inspector: when nothing is selected it shows the sticker itself (shape, size, finish, background), when something is selected it shows that item (position, size, rotation, fill, stroke, text). The bottom bar is the quote: print check, quantity with price breaks, total and one primary action.

    Review note · Figma-style tools: Move (V), Hand (H or hold Space), Text (T), Rectangle (R), Ellipse (O), Line (L), Pencil (P), shapes library, image (Ctrl+Shift+K). Marquee and Shift-click multi-select, Alt-drag duplicates, groups (Ctrl+G), lock/hide, drag-to-reorder layers, align and distribute, flip, copy/paste properties (Ctrl+Alt+C/V), numeric fields you can drag to scrub or type math into (e.g. 1.5*2), right-click menu, Shift+1 zoom to fit, Shift+2 zoom to selection. "?" opens the shortcut sheet.

    Review note · order flow (from the Print MCP spec): quote before commit, production-aware feedback, proof, then checkout. The print check uses the spec's codes (TEXT_TOO_SMALL, RESOLUTION_TOO_LOW, OUTSIDE_SAFE_AREA, LOW_CONTRAST, THIN_LINE…) with a message, a suggestion and a one-click Fix. "Review & order" opens the proof and quote; Add to cart creates a draft order through window.CustomGeniePrint, an adapter shaped like get_quote / create_proof / create_checkout so the backend can be swapped in. No card data is ever collected in the builder.

    Review note · Genie AI: Genie lives in the left panel as a conversation: describe a sticker (or attach artwork) and it asks only for what's missing, then shows four editable designs. With a design on the canvas it also takes edits ("navy and gold", "make it a circle", "change the text to …", "bigger text", "add a star"). In this prototype it runs on browser rules. For production, define window.CustomGenieAI.generate({mode, prompt, answers, logo}) and optionally window.CustomGenieAI.edit({prompt, doc}); both return the same document format.
